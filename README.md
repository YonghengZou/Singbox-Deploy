# Singbox 一键部署

这是一个用于在 Linux 服务器上快速部署 sing-box + Reality + Nginx 订阅服务的 Bash 脚本项目。脚本会自动完成安装、生成密钥、写入服务端配置、开放端口、生成订阅文件，并提供可直接使用的订阅链接。

## 1. 项目目标

这个项目的主要目标是把一个可用的 sing-box 服务端部署流程自动化，减少手动配置的步骤。

脚本会做的事包括：

- 安装 sing-box
- 生成或复用 UUID、Reality 密钥对、ShortID
- 写入 sing-box 服务端配置
- 启动并配置系统服务
- 放行相关端口（UDP/TCP 规则）
- 安装 Nginx 并提供订阅文件下载服务
- 生成通用订阅和 Clash / Clash Box 专用订阅

## 2. 适用环境

建议在以下环境下使用：

- Debian / Ubuntu 服务器
- root 权限或具有 sudo 权限的用户
- 可访问互联网的服务器

## 3. 主要文件

- [deploy_singbox_full.sh](deploy_singbox_full.sh)：完整部署脚本

## 4. 使用方法

### 4.1 先下载脚本

```bash
git clone https://github.com/YonghengZou/Singbox-Deploy.git
cd Singbox-Deploy
```

### 4.2 赋予执行权限

```bash
chmod +x deploy_singbox_full.sh
```

### 4.3 运行脚本

```bash
sudo ./deploy_singbox_full.sh
```

默认情况下脚本仍然可以一键部署，但会优先使用更安全的默认行为：

- 不会把完整密钥和 VLESS 链接直接暴露在终端输出中
- 会把部署详情保存到系统目录中的文件中，便于后续查看
- 仍然支持通过环境变量轻量自定义端口和伪装域名

如果你想在终端中查看完整细节，可以这样运行：

```bash
SHOW_SECRETS=1 sudo ./deploy_singbox_full.sh
```

如果你想自定义端口或 SNI：

```bash
LISTEN_PORT=443 SUB_PORT=8443 REALITY_SNI=example.com sudo ./deploy_singbox_full.sh
```

> 如果当前用户没有 sudo 权限，请先切换到有权限的账号执行。

## 5. 脚本会做什么

### 5.1 安装 sing-box

脚本会先检查系统中是否已经安装了目标版本的 sing-box。如果已经是目标版本，就会跳过安装；否则会自动下载安装。

### 5.2 生成或复用密钥

脚本会生成或复用以下内容：

- UUID：客户端身份标识
- PrivateKey / PublicKey：Reality 连接所需密钥
- ShortID：Reality 的短 ID

这些信息会被保存到系统目录中，后续再次执行脚本时会自动复用，避免因为重新生成导致旧客户端失效。

### 5.3 写入 sing-box 配置

脚本会生成一个服务端配置文件，并启用 VLESS + Reality 模式。默认监听端口为 443，适合常见的透明代理场景。

其中有一个关键变量叫做 `REALITY_SNI`，它的作用是设置 Reality 握手时使用的伪装域名，也就是 TLS 握手时看起来像在访问的目标域名。这个值通常写成像 `swdist.apple.com` 这样较常见、较自然的域名，用来让流量更像正常网站访问。

为什么有时需要换成其他域名：

- 某些网络环境下，当前域名可能不够稳定或被限制
- 你可能想换成更常见、更加容易被接受的伪装域名
- 不同地区或不同客户端环境，对伪装特征的兼容性可能不同

如果你需要更换，可以在脚本中把 `REALITY_SNI` 的值改成你想使用的域名即可。

### 5.4 启动服务并放行端口

脚本会：

- 启用 sing-box 的 systemd 服务
- 重启服务
- 配置防火墙规则
- 持久化保存 iptables 规则

### 5.5 生成订阅

脚本会生成两类订阅：

1. 通用订阅
   - 适用于 V2Box、v2rayNG、NekoBox 等客户端
   - 以 base64 编码形式提供

2. Clash / Clash Box 专用订阅
   - 适用于 Mihomo 内核客户端
   - 以 YAML 格式提供

这些订阅文件会通过 Nginx 暴露为 HTTP 下载地址。

## 6. 默认端口说明

脚本默认使用这些端口：

- 443：sing-box 监听端口
- 8443：订阅文件访问端口

如果你的环境已有冲突，请根据实际情况修改脚本中的端口变量。

## 7. 兼顾安全与一键部署

这个项目保留了“一键部署”的体验，但在安全性上做了几项默认增强：

- 默认不在终端直接打印完整密钥和 VLESS 链接
- 生成的敏感信息会写入系统目录中的受保护文件
- 仍然支持通过环境变量快速自定义端口和伪装域名

这样做的好处是：

- 对新手来说，依然可以直接运行脚本完成部署
- 对有经验的用户来说，可以按需查看更完整的信息
- 不会因为安全增强而让部署流程变得复杂

## 8. 重要注意事项

### 7.1 云平台防火墙

即使服务器内部防火墙放行了，云平台的安全组 / NSG 也需要单独放行对应端口，否则外部无法访问。

### 7.2 订阅链接安全

生成的链接中包含敏感信息，请不要随意分享给不信任的人。

### 7.3 脚本可重复执行

脚本设计为幂等执行。也就是说：

- 已安装的内容会跳过
- 已生成的密钥会复用
- 已存在的防火墙规则不会重复添加

这让脚本适合多次运行和后续维护。

## 9. 生成结果

脚本执行完成后，终端会输出：

- 服务器 IP
- UUID
- PublicKey

- VLESS 链接
- 通用订阅链接
- Clash 专用订阅链接
